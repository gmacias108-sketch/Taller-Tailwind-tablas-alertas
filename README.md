# Taller-Tailwind-tablas-alertas

Proyecto desarrollado con Angular 21 y Tailwind CSS.

## Development server

Para iniciar el servidor de desarrollo:

```bash
ng serve
```

Luego abre el navegador en:

http://localhost:4200/

## Generar componentes

Para crear un componente:

```bash
ng generate component nombre-del-componente
```

## Compilar el proyecto

```bash
ng build
```

## Ejecutar pruebas

```bash
ng test
```

## Tecnologías

- Angular 21
- Tailwind CSS
- TypeScript
- HTML
